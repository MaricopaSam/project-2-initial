# Reflections Log

This document serves as a log of reflections on various topics, capturing insights, lessons learned, and personal growth. It is intended to help users track their thoughts and experiences over time.

Ai Effectiveness: Where did it Excel? Where did it struggle?
Claude performed well at the tasks given to it. I only have to ask for modifications one time.
The modifications happened during the uses of the test classes. Each class needed to me modified in some way.
Once given the error, Claude fixed its own mistake. I believe that the reason that it performed decently well is because of the 
prompts that were made for it. If I was less clear in my prompts, I feel that it would have struggled more. In particular with 
the correct properties and the making of constructors and such, I feel that it would have done worse.

Code Quality Comparison: Ai-Generated vs Manual
I will admit that generating the code was faster. When I first started the AI program at CGCC, Ai was not the best at coding.
It could more simple things but as you got more complex, it would begin to struggle. However, I think it came down to the model used, the prompt and how the technology has improved since then.
The naming conventions were correct and the structure was correct. The code had much more documentation and comments then I
typically put in my own code. 

Learning Experience: What did you learn about inheritance and Ai-assistance development?
This project reinforced what we talked about in class with the core parts of inheritance.
Creating an abstract base class (Shape3D) to hold a shared state like name and cold, while having
getSufaceArea() and getVolume() to child classes reminded me of my time learning about classes in previous
languages I have learned. But also this was the first time that I actively used polymorphism in a project.

On the AI side, I think the most important thing I learned was on the prompts. Reading the README and taking the
prompt advice I feel gave me better results than if I did not follow them. I feel that if I did not include "include Javadoc documentation"
I would not have gotten as good as a result.

Validation Process: How did you verify that the Ai-Generated Code was correct?
Each formula was verified against a different source (typically from the internet)
before moving forward in the project. I also used scratch paper and a calculator to make my own shapes to check the results.


Future Applications: How will you use AI tools on projects in the future?
In previous classes, I would only ever use AI to help me code when I found myself stuck on what to do, or
I kept getting the same errors over and over. I feel that AI in projects, especially coding work best as a guide/nudge
or starting point rather than the final answer. I will admit that AI does extremely reduces time spent on repetitive problems
but when it comes to the structure of the project, the edge cases and the correctness of tests and formulas, I feel that is best
left to the human in the loop.

Going forward, I plan to use AI for perhaps assistance with repetitive sections or just a skeleton. However,
it would have to be checked that it is generating correctly, that formulas are correct, naming conventions are followed, etc.
